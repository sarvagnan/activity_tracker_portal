# Run one person's Portal on a home server

The Portal will keep its authoritative database and application on a home server, with Android acting as a data-supplying Device rather than the system of record. Each installation serves exactly one Subject, who is also its Operator; the design will not introduce accounts or switchable profiles. Tailscale reachability is the initial authority for both Sender ingress and browser access: any reachable device may read or mutate the Portal in v1, and CSRF protection does not turn that trust model into a login system. Authorization remains an ingress concern so another mechanism can replace or augment it without changing domain behavior. Provisioning, hardening, availability, and reachability of the home server and its private network are deployment responsibilities outside this project. This preserves local ownership and automated ingestion without making a phone or hosted service authoritative.
