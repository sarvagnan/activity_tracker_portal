# Keep the Portal and Sender in one governed repository

The Portal server and Android Sender will be separately buildable participants in one GitHub repository governed by one Vouch store. Their shared `protocol/` tree contains versioned JSON Schemas and canonical positive and negative byte vectors consumed by the TypeScript and Python tests of each language that encodes or decodes wire messages (ADR 0040). Implementations use explicit encoders and decoders rather than generated domain models: schemas describe closed structure, while executable vectors define exact bytes, hashes, outcomes, and compatibility. The shared delivery contract can therefore change atomically under one acceptance pack, accepting mixed languages and handwritten mappings in exchange for preventing protocol behavior from drifting.
